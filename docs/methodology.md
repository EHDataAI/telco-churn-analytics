# Methodology

## Analytical design

This repository intentionally follows a small-model-first sequence:

1. prior-probability dummy baseline;
2. regularized logistic regression;
3. XGBoost as a nonlinear challenger;
4. model selection on validation data using PR-AUC;
5. threshold selection on validation data using maximum F1;
6. one final selected-model evaluation on the untouched temporal test set.

The test set is not used to choose the model or the decision threshold. Candidate-model test scores
are not generated. Candidate ROC/PR curves are validation-only, and test access starts after the
selected model and threshold are locked.

## Why PR-AUC is primary for model selection

Churn is the minority class (roughly 27-28% in the synthetic temporal partitions).
ROC-AUC remains reported, but PR-AUC directly summarizes the precision/recall trade-off for the
positive class and is therefore the primary validation metric in this benchmark.

## Cross-validation

The train partition is assessed using five-fold stratified cross-validation with a fixed random
seed. CV is used to evaluate stability, not to replace the temporal validation/test design.

## Calibration and decision thresholds

Probability quality is checked with the Brier score and a calibration plot. A default threshold
of 0.50 is reported during candidate comparison, but the operational demonstration selects an
F1-maximizing threshold using validation only.

No business cost ratio is invented. A cost-sensitive threshold should be introduced only when
real intervention costs and churn value assumptions are available.

## Targeting metrics

The final evaluation also reports precision, recall and lift in the highest-risk 5%, 10%, 20%
and 30% of customers. These measures translate model ranking performance into a form closer to a
retention campaign workflow.

## Interpretability

Logistic coefficients are reported as regularized predictive coefficients. For standardized
numeric features, exponentiated coefficients correspond to a one-standard-deviation change on the
model scale. They must not be interpreted as causal effects.

Categorical coefficients are relative to the category omitted by one-hot encoding.

## Responsible-AI diagnostics

Gender and age-band subgroup metrics are produced as diagnostics even though Gender is not used by
the primary model. These tables are not a fairness certification and do not establish equalized
odds or absence of disparate impact.

## Scope limitation

All reported model results describe the synthetic benchmark generated by this repository. They are
not estimates of real telecom churn performance and should not be used to make production claims.
