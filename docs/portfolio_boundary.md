# Public / private boundary

| Component | Classification | Public repo? | Rationale |
|---|---|---:|---|
| Synthetic train/validation/test CSVs | PUBLIC | Yes | Fully synthetic and generated by repository code |
| Data dictionary and dataset card | PUBLIC | Yes | Required for interpretation and reproducibility |
| `src/`, tests, scripts, notebooks | PUBLIC | Yes | Core technical evidence |
| Generated benchmark metrics/figures | PUBLIC | Yes | Reproducible evidence from synthetic data |
| Original academic CSVs | INTERNAL | No | Reference only; unnecessary for public reproduction |
| Original academic notebooks | INTERNAL | No | Preserve history but contain methodological/software debt |
| Word/PDF academic deliverables | INTERNAL | No | Redundant with curated documentation |
| Presentation video | SENSITIVE/INTERNAL | No | Contains identifiable participants and browser context |

No public file should contain credentials, private paths or identifiable real customer records.
